The programming question this time is based around the mythical RCx8 processor. The instruction set for the processor is included in these files. A program for the processor is included in the binary file rcx8.prg. All memory should be cleared to zero prior to running the program.

File format of *.prg:
A *.prg file consists of blocks. Blocks begin on word boundaries. The first word denotes the block type.

Block type 0x0000: end of file

Block type 0x1000: comment
word: length
byte: data bytes follow, ascii comment

Block type 0x2000: data
word: loading address
word: length of data
byte: data bytes follow

Block type 0x7000: start address
word: program start address

When you run the program you will find your answer to this problem.
